Test_Doc

Funzionalità

Le principali funzionalità offerte dal progetto sono:

  • Gestione della documentazione tecnica in Markdown e HTML.
  • Struttura modulare e facilmente estendibile.
  • Pagine statiche pronte per essere pubblicate su un web server.
  • Esempi pratici di esercizi di programmazione.

Guida rapida

Segui questi passi per iniziare a usare il progetto:

  1. Clona il repository dal sistema di controllo versione.
  2. Apri la cartella Test_Doc nel tuo editor preferito.
  3. Apri il file index.html nel browser.
  4. Modifica i contenuti seguendo gli esercizi proposti.

Documentazione

La documentazione completa è disponibile nella cartella Docs. Di seguito i documenti principali:

  • Installazione — istruzioni di setup del progetto.
  • README — panoramica generale.
